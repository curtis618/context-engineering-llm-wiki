# 證據卡：Context Rot
wiki: concepts/context-rot.md

- **ROT-1** 一般假設模型會平均地使用整段上下文；Chroma 的實驗顯示不是，輸入越長，表現越不可靠。 [S4]
- **ROT-2** Chroma 測試了 18 個模型，包含 GPT-4.1、Claude 4、Gemini 2.5 與 Qwen3 系列。 [S4]
- **ROT-3** 實驗刻意讓任務保持簡單，只改變輸入長度，所以量到的是「長度本身」的影響。 [S4]
- **ROT-4** 干擾句（和問題相關但不是答案的句子）：只加一個，表現就比沒有干擾時差；加到四個更差。 [S4]
- **ROT-5** 順序正常、前後連貫的長文，反而比句子被隨機打亂的長文更難找到答案，18 個模型都是如此。 [S4]
- **ROT-6** 對話記憶測驗：只給相關片段（約 300 token）時的表現，明顯高於給完整歷史（約 113k token）時。 [S4]
- **ROT-7** Anthropic 的描述：視窗裡的 token 越多，模型準確回想其中資訊的能力就越低；所有模型都有這個現象，只是程度不同。 [S5]
- **ROT-8** 原因之一：訓練資料裡短的文字比長的多，模型處理長距離關係的經驗比較少。 [S5]
