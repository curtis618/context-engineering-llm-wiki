# 證據卡：寫入
wiki: concepts/write-context.md

- **WRI-1** 草稿區：任務進行中做的筆記，可以寫進檔案，也可以存在程式執行狀態的一個欄位。 [S2]
- **WRI-2** 結構化筆記：agent 定期把筆記寫到視窗外的記憶，之後再讀回來，例如待辦清單或 NOTES.md 檔。 [S5]
- **WRI-3** 例子：玩寶可夢的 Claude 會記錄數量與地圖，上下文被重置後靠讀自己的筆記繼續。 [S5]
- **WRI-4** Manus 的 agent 會建立 todo.md 並逐步改寫、勾掉完成的項目，讓整體目標一直留在上下文的最後面。 [S6]
- **WRI-5** 長期記憶：跨對話保存的記憶，ChatGPT、Cursor、Windsurf 都會自動產生這類記憶。 [S2]
